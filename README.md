# SortZen

SortZen is a Windows desktop program that sorts messy folders, such as Downloads, into the
right destination folders. It learns from folders that are already sorted and from
corrections made on its review screen, and only asks an AI service about files it can't
place by itself.

- Local first: files are read and sorted on the PC; AI is optional.
- Nothing moves until the review screen is confirmed, and every run can be undone.
- Privacy settings control exactly what, if anything, is sent to an AI service.

Status: planning. See `docs/SPEC.md` for what SortZen does and `docs/ROADMAP.md` for the
build plan.
